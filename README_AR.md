# متجر الفخامة — دليل الإعداد

هذا المشروع واجهة متجر عربية متجاوبة، مع لوحة إدارة لتسجيل الدخول وإضافة/تعديل/حذف المنتجات والتصنيفات ورفع صور المنتجات. يحتاج إلى Supabase لقاعدة البيانات وتسجيل الدخول وتخزين الصور.

## تنبيه مهم حول الاستضافة
GitHub Pages يستضيف ملفات ثابتة فقط، ولا يوفر قاعدة بيانات أو صلاحيات إدارة من تلقاء نفسه. كما أن سياسة GitHub Pages لا تسمح باستخدامه لاستضافة متجر إلكتروني تجاري. يمكنك حفظ الكود في GitHub، ونشر الموقع على Vercel، وربطه بـ Supabase. راجع سياسة GitHub Pages قبل اختيار الاستضافة.

## 1) إنشاء مشروع Supabase
1. أنشئ مشروعاً على https://supabase.com/.
2. من Authentication > Users، أنشئ مستخدماً واحداً لك بالبريد وكلمة مرور قوية.
3. عطّل التسجيل العام للمستخدمين (Allow new users to sign up) من إعدادات Authentication.
4. افتح SQL Editor، ثم الصق محتوى `setup.sql` بعد استبدال `admin@example.com` ببريدك الإداري الحقيقي، ونفّذه.
5. من Project Settings / API أو Connect، انسخ Project URL وPublishable key (أو anon key القديم). لا تستخدم `service_role` أو secret key في الموقع.

## 2) إعداد config.js
استبدل:
- `https://YOUR-PROJECT-ID.supabase.co` بعنوان مشروعك الحقيقي.
- `YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY` بالمفتاح العام Publishable/anon.
- رقم واتساب مضبوط مسبقاً: `218925686579`، أي الرقم الليبي مع مفتاح الدولة ودون الصفر الأول.

المفتاح العام يمكن أن يظهر في المتصفح؛ الأمان الحقيقي هنا يعتمد على سياسات RLS في `setup.sql`. لا تضع مفتاح `service_role` في ملفات الموقع.

## 3) تجربة الموقع
افتح `index.html` عبر استضافة HTTPS. افتح `admin.html` وسجّل الدخول بحساب المسؤول الذي أنشأته. من لوحة الإدارة يمكنك إضافة التصنيفات والمنتجات، تعديل المنتجات، رفع الصور (حد 5 ميغابايت للصورة)، وحذف المنتجات والتصنيفات.

## 4) النشر
- ارفع ملفات المشروع إلى مستودع GitHub.
- اربط المستودع بـ Vercel واختر النشر كموقع ثابت دون build command، ومجلد الإخراج `.`.
- بعد النشر، افتح الموقع العام واختبر لوحة الإدارة.
- في إعدادات Supabase Authentication > URL Configuration، أضف رابط الموقع المنشور إلى Site URL وRedirect URLs عند الحاجة.

## ملاحظات أمنية
- استبدل البريد في جميع سياسات `setup.sql` بنفس البريد الذي تستخدمه للدخول. البريد حساس لحالة الأحرف بحسب إعدادات المصادقة، لذا اكتبه كما يظهر في حسابك.
- عطّل إنشاء الحسابات العامة؛ وإلا قد يستطيع أي شخص إنشاء حساب، لكن سياسات RLS ستمنعه من التعديل ما لم يطابق بريده البريد الإداري.
- لا تشارك كلمة مرور المسؤول، ولا تضع أي مفتاح سري في GitHub.
- حذف تصنيف مرتبط بمنتجات قد يفشل؛ انقل المنتجات إلى تصنيف آخر أو احذفها أولاً.
- حذف المنتج لا يحذف ملف الصورة من التخزين تلقائياً؛ يمكنك تنظيف الصور القديمة من Storage يدوياً.
